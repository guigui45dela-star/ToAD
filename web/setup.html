Choisissez votre mode d'installation

Local (Recommandé)
BloodHound CE est inclus dans ToAD. Installation tout-en-un, parfait pour démarrer.
Remote
Connectez-vous à une instance BloodHound existante. Pour les utilisateurs avancés.
Mode local : ToAD va démarrer BloodHound CE, PostgreSQL et Neo4j automatiquement. Vous n'avez rien d'autre à installer.
Mode remote : Assurez-vous que votre instance BloodHound est accessible depuis ce serveur et que vous avez les identifiants.

Configuration BloodHound

En mode local, BloodHound sera automatiquement configuré. Définissez simplement les mots de passe.
Minimum 12 caractères, mélangez lettres, chiffres et symboles
Port accessible depuis votre navigateur
URL complète de votre instance BloodHound

Configuration Neo4j

Neo4j est la base de données utilisée par BloodHound. Définissez les identifiants.
