# Screenshots

Ce dossier contient les captures d'écran de ToAD pour la documentation.

## Screenshots à ajouter

- `dashboard.png` : Vue principale du dashboard avec la liste des clients
- `client-actions.png` : Modal d'actions client (import PingCastle, SharpHound, génération AD-Miner)
- `rappel-modal.png` : Modal de rappel avec les guides procéduraux
- `full-audit-form.png` : Formulaire d'audit complet
- `bloodhound-status.png` : Indicateur de statut BloodHound dans le header

## Comment prendre les screenshots

1. Lancez ToAD : `docker compose up -d`
2. Accédez à `http://localhost:9100`
3. Utilisez un outil de capture d'écran (Snipping Tool, Flameshot, etc.)
4. Sauvegardez les images dans ce dossier
5. Mettez à jour ce README avec les descriptions

## Résolution recommandée

- Largeur : 1920px ou 1440px
- Format : PNG
- Compression : Optimisée pour le web

**Note** : Les screenshots ne sont pas versionnés (voir .gitignore). Ajoutez-les manuellement avant de publier la documentation.
